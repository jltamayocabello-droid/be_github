# Temario

## Comandos Básicos

- `git init`: Inicializa un nuevo repositorio de Git en el directorio local.
- `git clone`: Clona un repositorio remoto existente en tu máquina local.
- `git status`: Muestra el estado de los archivos (sin seguimiento, modificados o en staging).
- `git add`: Agrega archivos o cambios al área de preparación (*staging area*).
- `git commit`: Guarda los cambios en el historial del repositorio con un mensaje descriptivo.
- `git branch`: Lista, crea o elimina ramas.
- `git checkout`: Cambia de rama o restaura archivos en el espacio de trabajo.
- `git merge`: Fusiona los cambios de una rama a la rama actual.
- `git remote`: Gestiona los repositorios remotos vinculados al proyecto.
- `git fetch`: Descarga el historial y referencias de un repositorio remoto sin aplicar los cambios.
- `git pull`: Descarga y fusiona los cambios de una rama remota en la rama local actual.
- `git push`: Envía los commits locales al repositorio remoto.
- `Fork`: Bifurcación de un repositorio en GitHub para trabajar en una copia propia.
